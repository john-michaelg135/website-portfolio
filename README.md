# website-portfolio
A personal portfolio website showcasing my academic journey, technical skills, and creative projects. It features a video walkthrough, contact page, and responsive design. The content reflects my IT background, interest in photography, and goal of building a professional identity.

## Features

- Glass-morphism UI design
- Responsive navigation
- Animated background
- Tab-based content organization
- Social media integration
- Project showcase
- Resume download
- Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
